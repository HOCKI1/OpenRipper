================================================================================
  OpenRipper v1.0.0 (x64 Windows)
  Open-source 3D Geometry and Model Ripper for Vulkan & RPCS3
================================================================================

[EN] QUICK START:
1. Run "OpenRipperLoader.exe".
2. Click "Browse..." and select your game executable (e.g. rpcs3.exe).
3. Select hotkeys:
   - Primary: '0' (top number row)
   - Secondary: 'Insert'
4. Click "Launch Game with OpenRipper".
5. In game, press '0' or 'Insert' to dump 3D geometry.
   You will hear an audio BEEP when capture starts and completes.
6. Exported .obj meshes will be saved into "C:\OpenRipperDumps\Frame_X\".
   Open and import them directly into Blender!

Alternative launcher:
- Drag and drop your game .exe onto "run_vulkan_capture.bat".

--------------------------------------------------------------------------------

[RU] БЫСТРЫЙ СТАРТ:
1. Запустите "OpenRipperLoader.exe".
2. Нажмите "Browse..." и выберите исполняемый файл игры (например, rpcs3.exe).
3. Проверьте клавиши (по умолчанию установлены клавиша '0' и 'Insert').
4. Нажмите "Launch Game with OpenRipper".
5. В игре нажмите '0' или 'Insert' для дампа 3D-геометрии.
   Прозвучит звуковой сигнал (бип) в начале и в конце захвата кадра.
6. Выгруженные .obj меши сохранятся в папку "C:\OpenRipperDumps\Frame_X\".
   Их можно сразу импортировать в Blender!

Альтернативный запуск:
- Перетащите .exe игры прямо на файл "run_vulkan_capture.bat".
