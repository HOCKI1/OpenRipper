================================================================================
  OpenRipper v1.3.0 (Windows x86 / x64)
  Open-source 3D Geometry and Model Ripper for Vulkan, DirectX 9, DirectX 11 & OpenGL
================================================================================

[EN] QUICK START:
1. Run "OpenRipperLoader.exe".
2. Click "Browse..." and select your game executable (.exe).
   Supports both 32-bit (x86) and 64-bit (x64) games!
3. Select Graphics API:
   - "Vulkan (Native / RPCS3)" for Vulkan and RPCS3 emulator
   - "DirectX 9 (D3D9 Injection)" for classic DirectX 9 games (x86 or x64)
   - "DirectX 11 (D3D11 Injection)" for DirectX 11 games (x64)
   - "OpenGL (GL Injection)" for OpenGL games and emulators (x86 or x64)
4. Select hotkeys:
   - Primary: '0' (top number row)
   - Secondary: 'Insert'
5. Click "Launch Game with OpenRipper".
6. In game, press '0' or 'Insert' to dump 3D geometry.
7. Exported .obj meshes will be saved into "C:\OpenRipperDumps\Frame_X\".
   Open and import them directly into Blender!

--------------------------------------------------------------------------------

[RU] БЫСТРЫЙ СТАРТ:
1. Запустите "OpenRipperLoader.exe".
2. Нажмите "Browse..." и выберите исполняемый файл игры (.exe).
   Поддерживаются как 32-битные (x86), так и 64-битные (x64) игры!
3. Выберите графический API:
   - "Vulkan (Native / RPCS3)" для Vulkan и эмулятора RPCS3
   - "DirectX 9 (D3D9 Injection)" для игр DirectX 9 (x86 и x64)
   - "DirectX 11 (D3D11 Injection)" для современных игр DirectX 11 (x64)
   - "OpenGL (GL Injection)" для игр и эмуляторов на OpenGL (x86 и x64)
4. Проверьте клавиши (по умолчанию установлены клавиша '0' и 'Insert').
5. Нажмите "Launch Game with OpenRipper".
6. В игре нажмите '0' или 'Insert' для дампа 3D-геометрии.
7. Выгруженные .obj меши сохранятся в папку "C:\OpenRipperDumps\Frame_X\".
   Их можно сразу импортировать в Blender!
